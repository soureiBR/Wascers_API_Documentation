Use com o seu agente de IA

Claude, ChatGPT, Cursor ou qualquer agente que faça chamadas HTTP consegue ler e consultar o Database do seu container. Basta passar a documentação e a sua URL base.

1

Crie a chave

No painel: Configurações → Chaves de API → Criar Chave de API, com o escopo database:access. Use a API Key (pk_…).

2

Gere o prompt

Preencha o domínio do container e a chave abaixo e clique em Copiar prompt.

3

Cole no agente

Cole o prompt e peça o que precisa, por exemplo: "ache as compras com gclid dos últimos 7 dias".

Prompt para o agente

Os valores ficam só no seu navegador. Sem a chave, o prompt usa a variável WASCER_API_KEY.


    


    
Arquivos para o agente

    

      
llms.txt
Índice da documentação no formato que agentes leem primeiro.

      
database-api.md
Guia completo em Markdown: autenticação, rotas, paginação, erros e regras para agentes.

      
openapi.json
Especificação OpenAPI 3, para ferramentas que geram cliente ou chamam a API sozinhas.

    


    
Boas práticas

    

      
    
        
  • A URL base contém a chave. Prefira guardar a chave numa variável de ambiente (WASCER_API_KEY) em vez de colar no chat.
    • 
        
  • O prompt pede que o agente só leia. Para gravar ou apagar dados, peça explicitamente.
    • 
        
  • Para cortar o acesso do agente, revogue a chave em Configurações → Chaves de API. Leva até 2 minutos.
