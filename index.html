Database API

Leia e grave no Database do seu container sGTM direto pela API, sem depender das tags no GTM. Use num sistema seu ou passe para o seu agente de IA (Claude, ChatGPT, Cursor).

1

Crie a chave

No painel: Configurações → Chaves de API → Criar Chave de API, com o escopo database:access. Copie a API Key (pk_…). Leva até 2 minutos para ativar.

2

Pegue o domínio

É o domínio do seu GTM server-side: <identificador>.soureicdn.com ou o domínio próprio, na aba Domínios do container.

3

Use

Preencha abaixo e escolha: Testar nas rotas (Try it out logo abaixo) ou Copiar prompt para IA e colar no seu agente.

Conecte o seu container

Os valores ficam só no seu navegador. Sem a chave, o prompt usa a variável WASCER_API_KEY.

Ver o prompt para o agente de IA 

        
Cole no agente e peça o que precisa, por exemplo: "ache as compras com gclid dos últimos 7 dias". Ele só lê, a menos que você peça para gravar ou apagar.

      

      
URL base para o seu sistema: https://<domínio>/wascer-api/<pk_…>/v1/store. A chave vai no caminho; trate a URL como senha.
