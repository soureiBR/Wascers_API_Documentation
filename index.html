Database API

Leia e grave no Database do seu container sGTM direto pela API, sem depender das tags no GTM. Serve para integrações, scripts e agentes de IA.

1

Crie a chave

No painel: Configurações → Chaves de API → Criar Chave de API, com o escopo database:access. Copie a API Key (pk_…). Leva até 2 minutos para ativar.

2

Pegue o domínio

É o domínio do seu GTM server-side: <identificador>.soureicdn.com ou o domínio próprio, na aba Domínios do container.

3

Teste aqui

Preencha abaixo e clique em Usar. Todas as rotas ficam prontas para o Try it out. Comece por GET /collections.

Testar com o seu container

Os valores ficam só no seu navegador.

URL base para o seu sistema: https://<domínio>/wascer-api/<pk_…>/v1/store. A chave vai no caminho; trate a URL como senha.
